Defence Lab

Practical Cybersecurity for the Modern Workplace

Security awareness training for people who don't work in security. Two formats: Courses build the why — a real incident, taken apart step by step, 6–8 minutes. Security Bytes give the how — one specific thing to set up or check, 2–3 minutes. Both stand alone, and both stack into a path.

This is a live preview. Items marked planned are written into the catalogue but not built yet — the numbering follows the catalogue, so it stays stable as the rest arrives. Content and design are in active development.
