# Practical Cybersecurity for the Modern Workplace

Interactive cybersecurity awareness training for non-technical employees.

**Two formats:**
- **Courses** (`/courses`) — 10–12 slides, 6–8 min. Story, depth, practice. Own the *why*.
- **Security Bytes** (`/bytes`) — 4 steps, 2–3 min. Step-by-step action. Own the *how-to*.

Self-contained HTML, no build step. Deployed via GitHub Pages → Cloudflare Pages.

## Structure
```
index.html          landing catalogue
/courses            course HTML files
/bytes              byte HTML files
/assets             shared assets (future)
```

## Status
In active development — courses and bytes added incrementally.
