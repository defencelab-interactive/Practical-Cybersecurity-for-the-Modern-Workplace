Click any word to mark it yourself — each click cycles it through [NAME] [COMPANY] [PROJECT] and back. Every copy of that word changes with it, so the prompt still reads sensibly.

What this cannot do

It finds shapes: an email address looks like an email address, an amount looks like an amount. It has no idea that Hartwell is a client, that “the Ashworth matter” is a case, or that a sentence about one person in a team of three identifies them to anyone who knows the team. Assume it missed something.

So use it as a second pair of eyes rather than a filter: read the cleaned version and ask whether anyone outside your organisation could work out who or what it is about. Most of the time the honest answer is to describe the situation instead of pasting the document.

Nothing you type here leaves this page. There is no server — the matching runs in your browser, which is the only arrangement that makes sense for a tool whose whole job is text you did not want to send anywhere.

Pairs with the course What You Paste Into AI. The test it gives is two questions: is this mine to hand over, and would I be relaxed if it came back out with my name on it. This page helps with the first one only.
